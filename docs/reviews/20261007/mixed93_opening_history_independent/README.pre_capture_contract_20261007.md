# Saved opening-history audit

This package is a source-only, independent standard-library checker for one future saved 12-state opening-control result. It consumes the producer's JSON result and receipt plus the already-pinned elastic JSON input. It does not import producer or cohesive-law modules, open NPZ data, query providers, solve a system, or compute eigenvalues.

case.json binds the 93-coefficient global-control fixture, 16 one-sided interface points, frozen load fractions, toy bilinear material values, unit conventions, tolerances, and producer source hashes. The opening result and receipt are bound by path and SHA-256; the independent output path remains pending root review. SOURCE_PINS.json is deliberately disabled; this source package has not run its checker.

After source review, root may bind the saved inputs and authorize one audit with an exact GO token. The checker then verifies binary/JSON agreement, Hplus-Hminus, rigid trace reproduction, opening and force reconstruction, unit-response equilibrium, pointwise irreversible history, exact unload/reload work, total energy, and the requested partial/full failure checkpoints. It writes an exclusive compact JSON diagnostic.

The area weights represent one physical side once: their sum must be R*L = 1e-4 m^2, so full toy-law dissipation is A*Gc = 1e-6 J. Per-point law energies are J/m^2; area-weighted cohesive energies and bulk energies are J; traction is Pa; generalized force is N; stiffness is N/m.

Any later checker pass remains a fixed-face toy-path diagnostic. The fixture is not a ceramic calibration. Exact path subdivision verifies analytic bookkeeping only and does not establish solver convergence, crack growth, mixed-mode behavior, or physical qualification.
