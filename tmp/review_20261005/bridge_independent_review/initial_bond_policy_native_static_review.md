## Static pass/fail-path audit

- Actual audit JSON and TOML are independently bounded-read and SHA-256 checked against required external values, and the TOML's embedded JSON path/SHA must match the resolved actual JSON (`initial_bond_policy.jl:716-747`). At graph use both files and all evidence files are reread and rehashed (`:749-774`, `:694-715`). Evidence roles must be distinct from JSON/TOML paths.
- TOML parsing is exact-key and exact-shape, capped, finite-value checked, and rejects unsupported TOML value types (`:202-236`, `:304-585`). It recomputes the complete pair map and mask hashes and validates counts, full state partition, eligibility, native gate, zero-degree list, and planned-only physics metadata.
- The actual ordered CSV bytes are SHA-bound and parsed; header, canonical nonnegative IDs, uniqueness, finite coordinates, point cap, row order, and all three coordinates must equal TOML rows exactly (`:589-693`, `:694-715`). `Body.position` must match the declared single mm-to-m conversion and proper transform within `1e-12 m` absolute tolerance, with zero relative tolerance; the per-point horizon must equal the contract exactly (`:776-822`).
- `Body` permits the explicit policy only for `OSBMaterial` (`overlay/src/discretization/body.jl:100-132`). The native helper checks one chunk covering every body row. Threads and MPI multibody entry points reject policy-bearing setups (`overlay/src/core/threads_multibody_data_handler.jl:37-40`, `overlay/src/core/mpi_multibody_data_handler.jl:2-4`).
- The graph hook is after all raw `find_bonds!` calls and before physical `filter_bonds!` (`overlay/src/discretization/bond_system.jl:112-137`), which precedes halo discovery, localization, bond IDs, correction storage, and kernels (`:56-90`). It maps native indices to external IDs, requires every canonical candidate in both directed orientations exactly once, and rejects extra/missing/duplicate edges. It then filters only `IN_MATERIAL`, rebuilds `n_neighbors`, and checks the complete reciprocal included set (`initial_bond_policy.jl:862-958`).
- Unknown, empty candidate, empty included-mask, and zero-degree conditions cannot reach the native search: the transport eligibility must be recomputed and then the positive-degree candidate state is required before `find_bonds` (`initial_bond_policy.jl:490-525,776-801`). Geometry exclusions are counted separately from physical events and never alter `bond_active`, damage, or precrack state.

No concrete fail-open path was found in these statically checked gates, conditional on the expected digests actually coming from the trusted receipt. The first finding is therefore a trust-boundary prerequisite, not evidence that hashes independently authenticate provenance. Root should keep native and scientific claims blocked until the authorized isolated Julia tests and a later native readback/mechanical validation are complete.

## Follow-up static delta — MPI single-body entry

### P1 — MPI single-body scope bypass (guard staged; not runtime-verified)

The independent critic found one concrete scope bypass in the earlier snapshot: a policy-bearing body passed directly to `mpi_data_handler(body, solver)` was not covered by the multibody-only guard. The pinned base overload at `pgfrag/src/pgfrag/resources/julia/vendor/Peridynamics.jl/src/core/mpi_body_data_handler.jl:81-83` begins with `PointDecomposition(body, mpi_nranks())` and proceeds to `chop_body_mpi`; with one MPI rank this may yield the one chunk accepted by the native scope validator. Thus a policy body could enter the native mask path under MPI, contrary to the Threads CPU-only architecture. The multibody guard did not protect this direct body overload.

The updated isolated overlay adds `_reject_initial_policy_in_mpi_body(body)` as the first statement in the MPI single-body overload (`overlay/src/core/mpi_body_data_handler.jl:81-83`). It rejects every policy-bearing body while leaving the legacy no-policy path unchanged. The helper is at `overlay/src/discretization/initial_bond_policy.jl:834-837`; the focused source test at `tests/test_initial_bond_policy.jl:21-25` checks both legacy acceptance and policy rejection. The regenerated patch reconstructs all staged source files and the stdlib-only `Project.toml` hunk in memory. No patch application or Julia execution occurred, so the bypass is closed in staged source by static evidence only and this does not certify a compiled or native runtime.

The source pin manifest contains the unchanged prior base pins plus the new pinned base/overlay hashes and refreshed hashes for edited staged artifacts. `isolated_fork_compile_test_plan.md` documents a future authorized ≤180-second test on a disposable copy, using the existing depot read-only and prohibiting dependency installation, solver execution, production execution, and CAD.
