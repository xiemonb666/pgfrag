# Full 3-D consistent mass replay

This package prepares a bounded reader for the cached arrays in the fixed
operator result. It computes the raw semantic-order mass matrix

`M[(i,a),(j,b)] = rho * sum_q N_i(x_q) N_j(x_q) w_q delta_ab`

from the saved `basis.values`, the first 256 saved volume weights, and the
saved registry mapping. The scalar basis rows stay source-major with BASE then
FRONT_F1_UNSHIFTED; the full vector slots come from `registry.ordered_keys`.
The code does not invoke MLS, a provider, field-reference code, stiffness
assembly, or a solver.

`rho=1 kg/m^3` is a fixed toy diagnostic scale. It is explicitly marked
`NOT_MATERIAL_CALIBRATED`. The reader saves the raw `M` in kg and a CSV view,
component-block/trace checks, symmetry, and the complete spectrum of `M/(rho V)`.
It computes all six rigid-mode kinetic forms both from independent direct
volume integration and from the saved rigid coefficient vectors through `M`.
The three translation masses are compared with `rho V`; rotational inertia is
integrated about the saved source centroid and compared with the centered solid
cylinder formula.

Every one of the 162 mass modes is expected positive. A negative or near-zero
scaled eigenvalue blocks the diagnostic. The code does not lump rows, add a
ridge, truncate modes, or use a pseudoinverse. Cholesky is attempted on the
unmodified positive-scaled matrix only after the spectrum gate passes.

## Frozen inputs and execution gate

`fixed_case.json` pins the operator result path and SHA-256 supplied by the
main agent. The source pins file is re-read, and the recorded source hashes are
checked against the result. The fixed case currently has
`execution.authorized=false`; the entry point exits before importing NumPy
until the main agent authorizes the exact readback and updates the case SHA.
No mass matrix or numerical result has been generated by this package.

After authorization, the one-shot command should use the bundled runtime and
an external 10-second timeout:

  --expected-case-sha256 '<SHA-256 of the authorized fixed_case.json>'

The result JSON and matrix CSV are written under
`pgfrag/tmp/review_20261006/full3d_consistent_mass_replay_20261006/run01/`. Existing
outputs block reruns. The 8 MiB input, numeric-array, and result caps remain

quadrature, or density.
