# Exact finite-facet visibility stability

This source-only experiment adds an exact, bounded local-stability certificate for the finite triangular crack visibility primitive. It is geometry only and remains `NOT_COUPLED`: it does not model crack nucleation or growth, tetrahedral adjacency, material response, solver coupling, curved crack truth, or ceramic physics.

`certify_local_visibility_stability` takes fixed source positions, query positions, and explicit triangle facets in SI metres. Inputs must be plain C-contiguous float64 NumPy arrays. Shapes are capped at 500 sources, 500 queries, and 256 facets. Query/source pairs and source/query/facet work are each capped at 16,384. Metadata checks happen before bounded private copies; over-budget work returns immutable UNKNOWN results without converting coordinates, loading the float reference, or allocating per-facet output arrays.

Each float64 coordinate is treated as its exact dyadic rational value. Input numerator/denominator bit length is capped at 256 bits. Arithmetic checks conservative predicted Fraction operand bounds before constructing each operation and caps intermediate numerator/denominator bit length at 2,048 bits. A bit-budget overrun fails closed as UNKNOWN. No tolerance clipping, pseudoinverse, facet repair, or endpoint-plane-as-blocker rule is used.

For a nondegenerate facet, strict same-side source/query plane signs certify a finite-facet miss. Strict opposite signs give an exact segment/plane intersection. Strictly positive barycentric coordinates certify an interior blocking crossing; any strictly negative coordinate certifies a finite-facet miss; an edge/front point is UNKNOWN. A source or query exactly on the plane is checked against the finite triangle: a strictly negative barycentric coordinate certifies that the endpoint misses the facet, while an endpoint inside/on its edge is UNKNOWN. A coplanar segment or degenerate facet is UNKNOWN. The exact geometric candidate is accepted only when every facet is decisive and the pair status agrees with the frozen float classifier identified in `../explicit_visibility_20261005/visibility3d.py` by SHA-256 `9d5097ca33ce899cf788ad43ef0740a34296216a8fd7aa490868c27ffe1ebb03`.

Aggregation is all-facets-strict. If any facet is UNKNOWN, the pair is UNKNOWN even when another facet is a definite blocker. Complete facet statuses and reasons remain in the result for audit. A stable mask is true only for a pair whose full exact candidate and pinned float status agree. UNKNOWN is never visible.

The certificate states only that, in ideal real geometry, there exists some open neighbourhood of the query where the same finite-facet mask holds for the exact float coordinates supplied. It does not compute a radius, guarantee arbitrary IEEE perturbations, prove that a float rotation/unit conversion preserves the exact dyadic inputs, or validate physical truth. The float reference also has an absolute SI tolerance and a coordinate-precision guard that depends on absolute world-coordinate magnitude.

`test_stability3d.py` contains hand fixtures for strict hits/misses, finite-plane endpoint misses, front/edge/coplanar/degenerate uncertainty, blocker-plus-ambiguity aggregation, float/exact disagreement, no-facet identity, winding and rotation/scale covariance, input/intermediate budgets, immutable results, and preflight boundaries. These tests are source-only pending parent algebra review; they have not been run.
