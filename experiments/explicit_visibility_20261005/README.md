# Explicit crack visibility primitive

This is an isolated, source-only geometry primitive for the reviewed explicit-crack branch. It classifies each query/source segment against supplied triangular crack facets. `VISIBLE` is the only status that permits query-local support; `BLOCKED` rejects support, and `UNKNOWN` remains a separate fail-closed status.

Coordinates and tolerances use SI meters. Public inputs are exact C-contiguous NumPy arrays. Preflight caps are 500 sources, 500 queries, 256 facets, and 1,000,000 source-query-facet work pairs; the work cap is checked before value scans and private copies. The default local length tolerance is `1e-12 m + 1e-10 * max(segment_length, maximum_triangle_edge)`, raised to `32 * float64_epsilon * maximum_absolute_world_coordinate` when coordinate subtraction has less precision. Coordinates above `1e150 m` are rejected before float64 geometric work.

Facet degeneracy, endpoint proximity to a finite facet, coplanar or near-coplanar segment proximity, and edge grazing within the derived length tolerance produce `UNKNOWN`. A strict interior crossing produces `BLOCKED`. A point in a triangle's infinite plane but far from its finite triangle is not ambiguous by that fact alone. Degenerate facets make the cut set ambiguous; an independently proven interior crossing still returns `BLOCKED` because it rejects support decisively.

The implementation uses only supplied finite triangles. It does not read crack IDs, tetrahedral adjacency, or direction labels. This remains a geometry primitive: it does not implement nucleation, crack growth, a fracture criterion, solver coupling, or ceramic physics. Spatial derivative/local stability is `NOT_ESTABLISHED`; a fixed visibility pattern is not derivative evidence. No actual-data visualization adapter is included because this source review contains no mechanically coupled facet dataset to visualize.

`test_visibility3d.py` is a focused counterexample suite covering interior crossings and finite-facet misses, direction independence, rotated/translated covariance, endpoint/front/edge/coplanar/degenerate ambiguity, far coplanar misses, immutability, exact-array rejection, pre-copy budget guards, no-facet identity, a generic proper quarter-turn, reversed winding, and a `1e-3 m` fixture. One approved focused pytest run passed all 17 cases in 1,436 ms (pytest-reported 0.20 s, return code 0); the captured JUnit and streams are under `tmp/review_20261005/explicit_visibility_20261005/focused_test/run_20261005_01/`. No solver or renderer was run.
