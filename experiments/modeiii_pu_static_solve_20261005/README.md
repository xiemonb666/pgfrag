# Mode III scalar traction solve

This source-only experiment adds the fixed antiplane mechanics solve after the continuous MLS/front-PU operator bridge. It imports the frozen `ContinuousMLSFrontProvider`, `DofRegistry`, engineering-strain map, material and analytic field reference. Its own bounded adapter assembles only 54 scalar `u_z` coefficients, lateral `t_z` work, and the normalized physical mean row. It adds no MLS primitive, visibility mask, coefficient pin, pseudoinverse, ridge, or hidden null-mode removal.

The fixed source grid has 27 points and uses `R=0.01 m`, support radius `h=0.025 m`, `L=0.01 m`, `E=10^6 Pa`, `nu=0.3`, and `KIII=100 Pa sqrt(m)`. All 27 sources carry BASE and unshifted `FRONT_F1` UZ coefficients; all supports meeting the front is only a global algebraic bridge. The solve is restricted to the manufactured straight-front antiplane field. The branch cut remains `x<0, y=0`; the all-site enrichment does not establish local enrichment convergence.

The two volume rules compare GL4 radial × GL8 theta × GL4 z (128 points) with GL4 radial × GL16 theta × GL4 z (256 points). Theta is the only refined dimension; radial and axial orders remain four. This targets sensitivity to the half-angle front term and rational MLS angular rows. The comparison still leaves angular integration error possible and does not establish convergence. The same 64 side points load both levels, with two 32-point end-cap batches recording full traction while confirming scalar `t_z=0`. The independent off-grid check has 256 frozen points.

For each level the runner forms `K` from `grad(u_z)` and the pinned isotropic 6×6 constitutive matrix, and `f=∫side psi*t_z dS`. It assembles `c_a=(1/V)∫psi_a dV` and solves the diagonally scaled 55×55 Lagrange system for `cᵀd=0`. Before a solve it reports the symmetric-part scaled stiffness eigenvalues, roundoff reference, translation residual, quotient condition and scaled saddle condition. A missing or additional near-zero mode, inconsistent translation/gauge, nonpositive diagonal, failed direct solve, UNKNOWN provider row, budget violation, or timeout writes an UNKNOWN JSON and stops.

The JSON result is diagnostic only. It records the analytic-coefficient weak defect `K*d_star-f`, actual weak/gauge residuals, side force balance, solution energy and external work, and off-grid displacement/gradient errors normalized by `A*sqrt(R)` and `A/sqrt(R)`. It includes full cap traction records but excludes cap x/y work from the scalar UZ right-hand side. No numerical threshold qualifies the approximation or supports claims about full 3-D equilibrium, finite crack ends, fracture, SIF, or propagation.
