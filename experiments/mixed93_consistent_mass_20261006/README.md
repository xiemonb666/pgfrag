# Mixed93 consistent mass replay

This is a source-only primitive for the frozen 93-DOF mixed basis. It lifts the 31 cached scalar columns into the frozen semantic order: 81 source-major `SOURCE_BASE` components followed by 12 branch-major `GLOBAL_FRONT` components. The returned little-endian float64 byte string is the raw (M=\rho\int H^T H\,dV) matrix in kg. It stores no mutable matrix view.

The implementation processes the saved 512 volume rows in chunks of at most 256. It forms one scalar 31-by-31 Gram matrix, copies that matrix into the three semantic component blocks, and leaves cross-component entries exactly zero. The primitive applies no row-sum lumping, symmetrization, ridge, pseudoinverse, or mode truncation. Enriched basis values may be negative; this is why the consistent matrix is retained.

The fixed toy density is `1 kg/m³`, labeled `NOT_MATERIAL_CALIBRATED`. SI guards reject nonfinite or nonpositive weights and densities and cap individual weights, total volume, and density. The case now pins the independent recovery audit JSON as its `result_path` alias and the failed producer's saved NPZ by fixed SHA-256. The sibling producer `result.json` is still expected to be absent because the original producer exited with rc=1 after serialization failed. `execution.authorized` remains false pending root approval for one readback.

Before NumPy is imported or the NPZ payload is opened, the audit will verify a root-pinned independent recovery JSON against the fixed failed-array path/hash, 93-DOF layout, diagnostic-only status, and the original producer's actual rc=1/absent-result serialization failure. A mass audit can report its own diagnostic gate result while retaining the producer failure in its top-level status and provenance; it cannot convert the producer run into a successful solve.

The planned saved-only audit requires cached `semantic_ids`, `source_ids`, `volume_basis_values`, `volume_weights_m3`, `volume_xyz_m`, `source_positions_xyz_m`, and `rigid_coefficient_modes`. `volume_xyz_m` is needed to independently integrate physical translation and rotation kinetic forms; it cannot be replaced by source positions. The rigid fields use unit translational velocity (m/s) and unit angular velocity (rad/s); rotational coefficient entries carry length and do not calibrate density. It compares fitted and physical rigid velocities pointwise with a fixed `1e-10` normalized-error gate: translation errors are dimensionless, Rx/Ry errors divide by `sqrt(R²+(L/2)²)`, and Rz errors divide by `R`. The audit also checks the scaled raw-mass spectrum, component and symmetry diagnostics, all 36 rigid kinetic pairings, and centered-cylinder inertia formulas. The 6-by-6 kinetic matrix has block units of kg for translation/translation, kg·m for translation/rotation, and kg·m² for rotation/rotation. A failed stability gate blocks the mass diagnostic without changing density, basis values, quadrature points, or matrix treatment. No force solve, stiffness assembly, KKT system, generalized frequency calculation, CAD access, provider call, MLS query, or field reevaluation belongs to this task.

No numerical module import, NPZ payload read, assembly, solver, or pytest run is authorized in this source-only phase.
