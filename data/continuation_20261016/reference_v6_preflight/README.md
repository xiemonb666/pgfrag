# Reference vessel v6 native initialization preflight

Prepared for one native Akantu initialization-only invocation from the verified v6 tetra mesh. It uses the current `pgfrag/src/pgfrag` wrapper, mesh, and stability source frozen byte-for-byte under `inputs/`. The run command uses `--preflight-only`; it creates no solver steps or history arrays.

The MSH copy used by the wrapper changes only the two physical names needed by the wrapper (`cut_interface` → `interface`, `source_exterior` → `exterior`). `mesh.original.msh` is preserved byte-for-byte. [`parser_equivalence.json`](parser_equivalence.json) records raw Nodes/Elements block equality, raw tag/order equality, parsed connectivity equality, and the unchanged volume physical group. Exterior FID and role arrays are bound to each original MSH exterior triangle by its exact sorted original nodeTags key plus the MSH geometrical entity tag.

The source is a Daily Aberdeen 108x53, nominal 2 mm wall reference candidate, not a measured or physically qualified source profile. The run05 result reports 86,624 T4, 356 interface Tri3, and 44,182 exterior Tri3; OCC witness ancestry is conditional within declared CAD tolerances. The NPZ contains 25,748 node rows, of which 25,579 are T4-referenced; its 169 other original node tags are absent from the MSH Nodes block. No mesh node is pruned or renumbered. The audit records whether Akantu retains any NPZ-only tag and the actual native mass/DOF state. MSH↔NPZ T4 cells are bound by exact `original_cell_tags` and ordered corner `nodeTags`; this cross-format row permutation is separate from the native pre-insertion MSH row/local-corner contract. The meshed CAD-volume error is 0.240307997%; local foot-fillet area errors remain approximately −9.7% and do not qualify the whole feature. Material/interface values remain unvalidated cost-initialization placeholders, and the interface remains a preinserted weak seam.

The prepared forecast reserves less than the 268,435,456-byte whole-input/output budget, including the synthetic lineage JSON forecast. The full-history cap is 67,108,864 bytes; `preflight_only` returns before history allocation. The runner applies a 300-second WSL timeout and a separate 330-second PowerShell watchdog, with one thread per OMP/BLAS/MKL runtime and CPU 0 affinity. No runtime duration or solver-evolution cost is implied. Canonical STEP, upstream source STEP, source face lineage, run05 result, original MSH, alias MSH, T4 row-map, and FID/role-array hashes are frozen in `inputs/case.json`, `inputs/source_geometry_provenance.json`, and `run_control.json`.

The single attempt is run by `run_preflight.ps1` and audited by [`audit_preflight.py`](audit_preflight.py); [`native_initialization_audit.json`](native_initialization_audit.json) records the saved arrays and independent mass, volume, interface, loading, stability, and history-size checks. Two preparation validation failures occurred before any native process started; their receipts and partial input snapshots are preserved as `preparation_failure_01.json`, `preparation_failure_02.json`, `inputs.failed_preparation_01/`, and `inputs.failed_preparation_02/`. The attempt is diagnostic initialization only; it does not establish real-world geometry review, material validity, fracture, training eligibility, or solver qualification.
